# DevFest Hackathon 2026 — 参加時の必須事項

このOrganizationは、DevFest Hackathon 2026のチーム開発に使用します。参加者は次のルールを守ってください。

## 提出リポジトリについて

- 運営から招待された提出用リポジトリは**公開（Public）**です。開催中も運営・審査員・ほかの参加者が閲覧できます。
- GitHubから届いた招待は**7日以内**に受け入れてください。期限切れやメンバー変更があった場合は、すぐに運営へ連絡してください。
- 審査対象は、**提出期限までに提出用リポジトリへ置かれたコードと資料のみ**です。
- デプロイ済みの作品がある場合は、提出用リポジトリのREADMEにURLを記載してください。
- 提出期限後は提出用リポジトリが読み取り専用になり、pushできません。

## 開発方法

- 提出用リポジトリではGitHub ActionsとGitHub Pagesを利用できません。必要な場合は、このOrganizationなどに開発用リポジトリを別途作成してください。
- 開発用リポジトリで作業した場合も、期限までに最終版のコードと資料を提出用リポジトリへ反映してください。開発用リポジトリにしかない内容は審査対象になりません。

## 秘密情報をコミットしない

- APIキー、パスワード、サービスアカウント鍵などを**絶対にコミットしないでください**。
- 秘密情報は `.env` や `.dev.vars` などに保存し、`.gitignore` の対象にしてください。
- 開発用リポジトリから提出物を移す際は、過去のコミット履歴に秘密情報が含まれていないことも確認してください。
- 誤って公開した場合は、履歴から消すだけで済ませず、直ちにキーを無効化・再発行して運営へ連絡してください。
- GitHubのpush protectionに止められた場合は、対象の秘密情報をコミットから取り除いてください。
