# Co-Make

捨てる前に、つくってみる。

手元にある材料と工具から3つの工作案を選び、一人で制作を進めるスマートフォン向けWebアプリです。日英の工程を見ながら完成を記録し、作品をギャラリーへ任意で公開できます。

[画面確認用Preview](https://gdgoc2026-comake--dev-27-k8emdkdp.web.app/)

Previewでは材料に合わせたサンプル3案を表示します。確認版は `db4477f` から配備し、2026年11月14日15:25 JSTまで有効です。

## 使い方

1. 工具を選び、撮影または手入力で材料の名前・数量・単位を確定します。
2. 作品名・目安時間・難しさを見比べ、3案から1つを選びます。
3. 手順を1工程ずつ進め、写真あり・なしのいずれかで完成を記録します。
4. 好きな作品をギャラリーへ投稿し、コメント・いいね・保存で交流できます。前回の材料を使って新しい制作も始められます。

## 技術

フロントエンドはReact、TypeScript、Viteです。Firebaseの匿名認証で本人の制作を識別し、Cloud Firestoreに材料・案・進捗を保存します。Cloud Functionsで入力と所有者を確認し、Cloud Storageで写真を扱います。

Gemini APIを使う材料認識と3案生成はサーバー側に実装しています。材料ID・数量・工具・工程を検証し、同じ材料版の結果を再利用します。現時点の確認範囲はPreviewとEmulatorです。実モデル、実物制作、本番配備の検証はプロジェクトのIssueで追跡しています。

## 開発

開発用リポジトリはチームメンバー向けです。現行の仕様、セットアップ、テスト手順はリポジトリのREADMEと開発資料にまとめています。 [開発用リポジトリ](https://github.com/2026-GDGoC-UoA34/co-make)・[仕様v3.1](https://github.com/2026-GDGoC-UoA34/co-make/blob/main/docs/specifications/co-make-v3-1.md)

`npm run check` と `npm run test:emulators` で変更を確認し、専用ブランチのPRからmainへ統合します。
